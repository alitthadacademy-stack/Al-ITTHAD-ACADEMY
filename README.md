أكاديمية الاتحاد لكرة السلة 🏀
منصة رقمية متكاملة لإدارة اشتراكات وأنشطة أولياء الأمور واللاعبين بأكاديمية الاتحاد لكرة السلة.
🌟 مميزات المنصة
تسجيل اللاعبين واشتراكاتهم: إمكانية إدخال كود التحويل والبيانات بسهولة.
إشعار الواتساب التلقائي: توجيه ولي الأمر لإرسال تفاصيل التحويل وإيقاف/إرفاق الإيصال للمدرب مباشرة.
قواعد بيانات سريعة (Firebase Firestore): حفظ طلبات الاشتراك بأمان وبدون تكاليف إضافية.
لوحة تحكم للمشرفين: مراجعة وتفعيل الاشتراكات وإدارة الحضور.
